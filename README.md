# Comic Traffic

Comic Traffic is a React application for discovering and comparing movies, TV series, and comic books using a unified cumulative rating consensus.

## Development

- `npm start` starts the Vite development server at <http://localhost:3000>.
- `npm test` runs the Vitest suite once.
- `npm run build` creates the production site in `build/`.

The backend API is in `backend/ComicTraffic.Api`.
